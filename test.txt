Docker позволяет запускать приложения в изолированных контейнерах.

Dockerfile используется для описания образа контейнера.

Команда docker build создаёт Docker image.

Команда docker run запускает контейнер.

Docker Compose позволяет управлять несколькими контейнерами.

Docker Compose позволяет запускать несколько сервисов.
